# 平方麻雀 (Square Mahjong) for VRChat

8人・1316枚・なんでも倍の麻雀「平方麻雀」を、VRChat のワールドに置いて遊べるギミック(開発中)。

- ルール: ブラウザ版 https://monakalabo.github.io/baka-mahjong/ (ルールブック v0.8)
- 設計: [Documentation~/DESIGN.md](Documentation~/DESIGN.md)

## 開発のしかた

1. ALCOM で World テンプレートのプロジェクト(Unity 2022.3 / VRChat Worlds SDK 3.10 以降)を作る
2. このリポジトリをプロジェクトの `Packages/jp.monakalabo.square-mahjong` に置く
3. Unity でプロジェクトを開く
